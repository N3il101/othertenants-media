othertenants

Connect the TikTok account the daily post is published to.

One account is connected: @othertenants, owned by the person running this page. There is no sign-up and no second user.

What this asks TikTok for

user.info.basic Confirms the token belongs to the right account. Only open_id is read.
video.upload Sends the day's 60-second video to the account's inbox as a draft.
video.publish Not yet granted. In review, so the scheduled post can go out without a manual step.

What happens after you allow it

  1. TikTok returns to callback.html on this site with a one-time code.
  2. The operator exchanges that code for a token on their own machine. The client secret never reaches this page.
  3. A scheduled job sends one 60-second video a day to the account's inbox, where the owner publishes it.
